# 練習日程表メーカー（自分専用アプリ版）

スマホ・PCのホーム画面に置いて使える Web アプリ（PWA）です。
一度開けばオフラインでも動き、データは端末の中に保存されます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | アプリ名・アイコンなど（ホーム画面に追加するための情報） |
| `sw.js` | オフラインで動かすための仕組み |
| `icon-*.png` / `apple-touch-icon.png` | アプリのアイコン |

## 公開のしかた（GitHub Pages・無料）

ホーム画面に追加するには https のURLが必要なので、GitHub Pages で公開します。

1. https://github.com でアカウントを作り、ログインする
2. 右上の「＋」→「New repository」で、名前を `nittei` などにして **Public** で作成
3. 「uploading an existing file」を押し、このフォルダの中身（`index.html` など全部）をドラッグして「Commit changes」
4. リポジトリの「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分後、`https://（ユーザー名）.github.io/nittei/` で開けるようになります

※ Public リポジトリなのでアプリ本体は誰でも見られますが、**入力した日程は各端末の中だけに保存され、公開されません。**

## ホーム画面に追加

- **iPhone（Safari）**：上のURLを開く → 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：URLを開く → メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
- **PC（Chrome / Edge）**：URLを開く → アドレスバー右端のインストールアイコン

## データについて

- 日程は端末ごとに自動保存されます（スマホとPCで別々）
- 機種変更や別の端末に移すときは「バックアップを書き出す」→ 移した先で「バックアップを読み込む」
- ブラウザの「閲覧データを削除」をするとデータも消えるので、ときどきバックアップしてください

## アプリを更新したとき

`index.html` などを差し替えたら、`sw.js` の先頭の `VERSION = 'v1'` を `'v2'` のように上げてアップロードしてください。
次にアプリを開いたとき（2回目の起動で）新しい版になります。
